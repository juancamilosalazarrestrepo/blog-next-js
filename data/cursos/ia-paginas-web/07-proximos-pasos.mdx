## Ya tienes una web publicada. ¿Y ahora?

Terminaste tu primera página: está en internet, tiene tu propio dominio y la hiciste con IA
desde cero y gratis. Eso ya es un gran logro. Pero apenas empieza el camino para sacarle todo
el partido a esta nueva forma de trabajar.

<Callout type="tip">
  La mejor manera de aprender es construyendo. Ahora que sabes el flujo completo
  (prompt → código → ver en el navegador → subir a GitHub → desplegar), repítelo con ideas
  nuevas. Cada proyecto te vuelve más rápido.
</Callout>

## Ideas para tus siguientes proyectos

- Un **portafolio** para mostrar tu trabajo o tus estudios.
- **Diseños para un negocio o proyecto familiar**: un restaurante, una tienda, un consultorio.
- **Landing pages** para promocionar algo (un evento, un producto, tu CV).
- Un **blog** (como el que estás viendo ahora) con secciones y artículos propios.

Cada uno usa el mismo flujo que ya dominaste.

## Errores comunes y cómo evitarlos

| Error | Cómo evitarlo |
| --- | --- |
| Prompts vagos ("hazme una página bonita") | Sé concreto: tipo de web, páginas, colores, tono. |
| No previsualizar y esperar un resultado perfecto de una vez | Revisa en el navegador y pide ajustes en pasos pequeños. |
| Olvidar el diseño responsivo | Pide siempre que se vea bien en celular y tableta. |
| No usar Git/GitHub | Haz commits y pushes para no perder avances. |
| Desplegar sin probar | Verifica en local con `npm run dev` antes de publicar. |

<Callout type="nota">
  Pide también a la IA que te **explique** el código que genera. Entender poco a poco lo que
  hace tu página te dará mucha más confianza para dirigirla y mejorarla.
</Callout>

## De "mandar a la IA" a "dirigir a la IA"

La gran diferencia entre una persona que usa IA y una que la domina está en la **dirección**:

- La persona intermedia pide y se queda con lo que le dan.
- La persona avanzada **revisa, entiende, pide cambios y encadena** mejoras.

Cada proyecto te acerca a eso. Y las mejores habilidades que desarrollas (comunicar bien lo
que quieres, revisar con ojo crítico, iterar) te sirven para cualquier tecnología, IA o no.

## Despedida del curso

Hiciste algo que hace años requería semanas de estudio: **crear una página web desde cero,
gratis, con IA, y publicarla en internet con tu propio dominio**. Fíjate bien en tu enlace y
comparte tu logro. Cada vez que alguien lo abra, será el resultado de tu creatividad
combinada con tu nueva habilidad de dirigir a la IA.

Sigue construyendo. El siguiente proyecto está a un prompt de distancia.

## Para recordar

- Repite el flujo completo con nuevas ideas para volverte más rápido.
- Evita prompts vagos y revisa siempre el resultado en pantalla.
- Haz commits con Git y prueba en local antes de desplegar.
- Pídele a la IA que te explique el código para aprender más.
- Tu nueva superpoder es dirigir a la IA, no solo recibir lo que te da.
